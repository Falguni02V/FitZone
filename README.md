# FitZone
FitZone Premium: A complete MERN-stack Gym Management System featuring secure Google OAuth, live membership expiry tracking, interactive BMI calculators, and dynamic subscription upgrades. Members can uniquely request to change trainers with specific reasons. Powered by a sleek Light/Dark UI and an Admin SSR Dashboard for 1-click approvals.
You can view the website here at https://fitzone-premium.onrender.com/
